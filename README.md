# 티켓팅 스탠바이

티켓 예매 오픈을 **직접** 준비할 때 쓰는 브라우저 도구입니다. 자동 예매(매크로) 기능은 없습니다.

## 기능

- **카운트다운**: 오픈 시각까지 0.01초 단위로 표시
- **시간 보정**: 서버 응답의 `Date` 헤더를 여러 번 받아 내 기기 시계와 표준시의 차이를 계산 (수동 입력도 가능)
- **정각 알림**: 오픈 N초 전부터 1초마다 신호음, 정각에 긴 신호음과 화면 깜빡임 (Web Audio로 미리 예약하므로 다른 탭을 보고 있어도 정확히 울림)
- **준비 체크리스트**: 기본 항목 제공, 추가·삭제 가능 (서버에 저장되어 모든 방문자가 같은 목록을 봄)
- **보안문자 연습**: 영문 대문자 이미지 입력 연습, 정확도·평균·최고 기록 표시

## 로컬 실행

Node.js 18 이상이 필요합니다. 외부 패키지는 쓰지 않습니다.

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

## 관리자 페이지

`/admin` 주소에서 관리자로 로그인하면 다음을 할 수 있습니다.

- **오늘 현황**: 오늘 방문자 수, 페이지 조회, 보안문자 연습 횟수, 체크 횟수와 최근 7일 기록 (한국 시간 기준)
- **공지 배너**: 메인 화면 맨 위에 공지 문구를 띄우거나 숨김
- **공연·오픈일시**: 공연 이름과 오픈 시각을 정하면 모든 방문자의 카운트다운에 적용
- **체크리스트 관리**: 항목 문구 수정, 순서 변경, 개별 삭제, 기본 항목 복원, 전부 삭제, 방문자 추가·삭제 잠금

- 비밀번호는 코드에 없고, 서버의 `ADMIN_PASSWORD` 환경변수에서 읽습니다. 설정하지 않으면 관리자 로그인이 꺼집니다.
- 비밀번호 확인과 삭제 권한 확인은 모두 서버에서 합니다. 로그인하면 2시간 동안 유지되는 쿠키(HttpOnly, SameSite=Strict)가 발급됩니다.
- 같은 IP에서 15분 안에 5번 틀리면 15분 동안 로그인이 막힙니다.

로컬에서 실행할 때:

```bash
ADMIN_PASSWORD=원하는비밀번호 npm start
```

## Railway 배포

1. [Railway](https://railway.com)에 로그인하고 **New Project → Deploy from GitHub repo**를 고릅니다.
2. 이 저장소와 브랜치를 선택합니다.
3. 배포가 끝나면 서비스의 **Settings → Networking → Generate Domain**으로 공개 주소를 만듭니다.

4. 서비스의 **Variables**에 `ADMIN_PASSWORD`를 추가합니다.
5. 할 일 목록을 재배포 후에도 유지하려면 서비스에 **Volume**을 붙이고(마운트 경로 예: `/data`), Variables에 `DATA_DIR=/data`를 추가합니다. 볼륨이 없으면 다시 배포할 때마다 기본 목록으로 돌아갑니다.

포트는 Railway가 넣어 주는 `PORT` 환경 변수를 그대로 씁니다. 상태 확인 경로는 `/health`입니다.

## 구조

```
public/index.html   페이지 본체
public/admin.html   관리자 페이지 (/admin)
public/sync.txt     시간 보정용 파일 (서버 응답의 Date 헤더를 읽음)
server.js           정적 파일 서버 + 할 일 API + 관리자 인증
railway.json        Railway 배포 설정
```
