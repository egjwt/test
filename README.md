# 티켓팅 스탠바이

티켓 예매 오픈을 **직접** 준비할 때 쓰는 브라우저 도구입니다. 자동 예매(매크로) 기능은 없습니다.

## 기능

- **카운트다운**: 오픈 시각까지 0.01초 단위로 표시
- **시간 보정**: 서버 응답의 `Date` 헤더를 여러 번 받아 내 기기 시계와 표준시의 차이를 계산 (수동 입력도 가능)
- **정각 알림**: 오픈 N초 전부터 1초마다 신호음, 정각에 긴 신호음과 화면 깜빡임 (Web Audio로 미리 예약하므로 다른 탭을 보고 있어도 정확히 울림)
- **준비 체크리스트**: 기본 항목 제공, 추가·삭제 가능 (브라우저에 저장)
- **보안문자 연습**: 영문 대문자 이미지 입력 연습, 정확도·평균·최고 기록 표시

## 실행

`index.html`과 `sync.txt`를 같은 폴더에 두고 웹 서버로 열어야 자동 시간 보정이 작동합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다. 파일을 더블클릭해서 열면 자동 보정 대신 수동 보정만 사용할 수 있습니다.
